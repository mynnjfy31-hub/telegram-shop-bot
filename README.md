# Telegram Shop Bot 🛒

A complete and interactive Telegram bot designed for local e-commerce shops. This bot allows customers to view a product catalog, check prices and stock availability, and view product images directly within Telegram.

## ✨ Features
- **Product Catalog:** Browse a list of available products.
- **Product Details:** View price, stock status, and high-quality images for each item.
- **Contact Info:** A built-in button for customers to contact the shop directly.
- **Database:** Uses SQLite for fast and lightweight data storage.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Telegram API:** `pyTelegramBotAPI` (telebot)
- **Database:** SQLite3
